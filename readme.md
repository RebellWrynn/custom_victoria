Как использовать
Шаг 1: Запустить сборщик событий
bash

python3 collect_events.py

Он будет работать в фоне и записывать все события доступа в файл access_events.log.

Пример вывода:
text

================================================================================

📁 Writing to: access_events.log
⏹️  Press Ctrl+C to stop
================================================================================

[   1] Aug 11 13:29:50 | 00E00624 | CONT 1.3 Вх Гр Д      | 6b308596... | APPROVED
[   2] Aug 11 13:29:52 | 00E006ca | CONT 1.4 Вх Гр У      | 05b2d39b... | APPROVED
[   3] Aug 11 13:30:09 | 00D00000 | CONT 2.1 Вх Гр        | 50d2484e... | APPROVED
[   4] Aug 11 13:30:15 | 00E006c7 | CONT 1.4 Вх Гр У      | 6b308596... | DENIED

Шаг 2: Найти все записи для конкретного ключа
bash

python3 extract_keys.py 6b30859600000000

Дополнительные возможности
Поиск по L3-адресу (все ключи для двери)
bash

grep "00E00624" access_events.log

Поиск по пользователю
bash

grep "00800050335" access_events.log

Поиск по статусу (только отказы)
bash

grep "DENIED" access_events.log

Просмотр последних 10 событий
bash

tail -10 access_events.log
